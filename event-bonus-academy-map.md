## How We Will Analyze Weekly Updates

When new stats arrive, classify every opportunity as:

- `Locked`: already qualified.
- `On pace`: mathematically tracking.
- `Recoverable`: behind, but weekly gap is reasonable.
- `Long shot`: possible only with a major PR jump.
- `Not active / missing rules`: cannot evaluate yet.

Then choose the weekly focus:

- If production is low because activity is low: increase leads and booked appointments.
- If activity is high but production is low: fix close rate and average case size.
- If production is high but qualification risk remains: protect persistency and active app count.
- If multipliers are available: prioritize products with higher production credit when suitable for the client.
